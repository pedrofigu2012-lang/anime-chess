ANIME CHESS V15
Instale Node.js 18 ou superior. Extraia todos os arquivos na mesma pasta.
Abra um terminal nessa pasta e execute npm start.
Abra http://localhost:3000 em dois navegadores para testar.
No menu Multiplayer online, escolha o mesmo tamanho em ambos. Crie uma sala e informe o código ao segundo jogador.
Para jogar pela internet, hospede a pasta inteira em um serviço Node.js com HTTPS e comando npm start. GitHub Pages sozinho não executa o servidor.
Salas em memória, expiram após uma hora sem atividade. Coleção e recompensas locais, sem autenticação persistente ou validação de propriedade no servidor. Sem reconexão após recarregar. Efeitos online podem diferir do modo local.
